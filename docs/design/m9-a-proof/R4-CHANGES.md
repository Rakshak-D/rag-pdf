# M9-A-R4 changes from R3-F1

R4 keeps the conversation-first structure and optional PDF sheet. The changes below address the requested final design direction; this remains a static proof.

| Area | R3-F1 | R4 proof | Reason |
|---|---|---|---|
| Header | A visible top bar and status treatment. | No header band, border, or persistent model-status label. The provisional mark and RAG-PDF name sit left; two accessible ghost controls sit right. | Keep the header quiet and avoid an unverified ready state. |
| Type | Newsreader, Instrument Sans, and IBM Plex Mono were present, with extra comparison fonts wired into unused CSS. | Newsreader for answers, Instrument Sans for interface, IBM Plex Mono only for page/source metadata. Comparison families remain bundled for the local comparison page but are not in the reading interface. | Reduce visual and CSS competition while retaining the required local font study. |
| Spacing and answer | R3 used a 720px conversation shell and 18px answer type. | The R4 conversation shell is 840px; the answer stays capped at 66ch and uses 19px/1.65 on desktop, with 40px turn spacing. The composer remains fixed and the answer remains unboxed. | Give the conversation room while preserving a controlled reading measure and improving answer legibility. |
| Citations | Numbered citations and popovers existed. | Inline numbered chips stay with the claim's final word; keyboard focus and hover expose a short source quote; click opens the corresponding source page and verified mark. | Make citations a direct path to their evidence. |
| PDF sheet | The original page and evidence were shown in a larger optional sheet. | The sheet is closed by default, can be opened by a citation or explicit document control, and closes with Escape or its close button with focus restoration. The title is now screen-reader-only to avoid repeating the document name. | Keep reading optional and remove duplicate visible naming. |
| Source highlight | Citation targets were correct but mobile passages were too small in the R3 presentation. | Desktop citation zoom adapts to the target, capped at 200%. At 390px the target opens at 118%; every cited line is fully visible and measured 16.08–18.59px high. | Improve mobile inspection while preserving the original page image and coordinates. |
| Match view | Method labels could sit outside the visible PDF clip when the citation zoom was active. | Enabling matches fits the page and dark method gutter together and frames all five method labels in the viewport. The labels no longer collide with the page raster. | Make simulated method context visible where the matches are shown. |
| Document pill | The sample identity and page controls competed with the answer area. | The active sample appears inside the composer; its main control toggles the optional page sheet and its separate X removes it from the conversation only. | Make current document context available without a permanent viewer. |
| First run | R3 used shorter sample prompts and a response transition. | The exact three R4 prompts are shown without a heading; only the Link prompt has the deterministic pre-authored answer path. The other prompts are supported by the source but do not fabricate an answer. | Keep the sample immediately usable while making proof limits clear. |
| Attachment and progress | The selected sample path was already local and limited. | The plus control remains optional. Only a byte- and SHA-verified copy of the bundled sample exposes its page-render action. Reading progress is a static page-3 composition, not a build or ingestion state. | Preserve independent attachment/viewer choices and avoid false parsing claims. |
| Unavailable model | The earlier unavailable state emphasized opening the PDF. | The status now names the local-model problem and next action; PDF viewing remains independent. | Give a useful next step without blocking document reading. |
| Logo candidates | R3's open-loop, waveform, and section-sign candidates were generic or too similar to document marks. | R3 marks A/B/C are discarded. R4 compares a marked-page symbol, a typographic swipe wordmark, and an RP monogram. Each is shown in monochrome and neutral-plus-lime treatments on dark and paper surfaces, with size examples and lockups. | Explore clearly different concepts without selecting a permanent mark. |
| Copy and surfaces | The proof included repeated status text and more setup language. | R4 removes visible ready status, shortens the method legend to Cited/Uncited, keeps the required exact unreachable/starting states, and uses the R4 warm paper `#F4F1E8` with the existing dark room `#16140F` and evidence lime `#D7FF3A`. | Reduce repeated copy and preserve the Light Table's restrained evidence palette. |

## Verification limits and remaining imperfections

- This proof contains no production frontend or backend change. It does not load a model, access a real index, or demonstrate generation.
- The answer and passage classifications are static fixtures. The highlighted geometry is verified for the Poppler raster assets only; production PDF.js conversion remains unverified.
- Mobile source marks fit at 118%, but the John Klein line has only 1.09px horizontal clearance at 390px. All marks remain uncut in the screenshot; this margin is tight.
- The exact required starting text includes the separately banned phrase “Model ready.” The copy scan therefore remains a disclosed C33 failure. The phrase was not silently rewritten.
- The three logo concepts remain review candidates. No permanent selection or originality/trademark conclusion is made.
